# blOb Bob Reaction Emojis

Six production PNG assets for reaction controls and Activity Cards.

| File | Reaction | Visual |
| --- | --- | --- |
| `like.png` | Like | Bob with a clear thumbs-up |
| `love.png` | Love | Heart-shaped Bob blob |
| `lol.png` | LOL | Upright Bob laughing with two tears |
| `rofl.png` | ROFL | Canted Bob laughing with two tears |
| `fire.png` | Fire | Bob with a compact flame lobe |
| `sad.png` | Sad | Soft downturned Bob |

All assets are 1254 × 1254 px RGBA PNGs with true transparent backgrounds,
consistent visual scale, centered artwork, and no human hands or feet.
