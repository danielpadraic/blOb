# blOb reaction emojis

Six production PNG assets for reaction controls and Activity Cards.

| File | Reaction | Visual |
| --- | --- | --- |
| `like.png` | Like | Blue smiling face with a thumbs-up |
| `love.png` | Love | Red smiling heart |
| `lol.png` | LOL | Yellow face laughing with two tears |
| `rofl.png` | ROFL | Yellow face laughing, one eye winking |
| `fire.png` | Fire | Smiling flame |
| `sad.png` | Sad | Blue blob with downturned mouth and two tears |

All assets are 1254 × 1254 px RGBA PNGs with true transparent backgrounds,
consistent visual scale, centered artwork, and no human hands or feet.
